# لوحة إدارة الإسحاقيين — Ishaqiyin Admin (Flutter)

تطبيق فلاتر **مستقل** لإدارة محتوى تطبيق الإسحاقيين. يتصل بنفس مشروع
Firebase (`mxqp-8d1e8`) ويتحكم في نفس المجموعات التي يقرأها تطبيق المستخدم.

> هذا هو نظير «لوحة التحكم المخفية» التي كانت داخل المشروع الأصلي (Expo/RN)
> في `components/AdminPanel.tsx`، أُعيد بناؤها كتطبيق فلاتر منفصل.

## الوظائف
- **تسجيل دخول المشرف** (مجموعة `admins`؛ يُنشأ الحساب تلقائياً عند أول دخول باسم جديد).
- **لوحة إحصائيات**: عدد الأقسام الرئيسية/الفرعية، الصوتيات، الكتب، الأجهزة.
- **إدارة الأقسام**: إنشاء قسم رئيسي، وإنشاء قسم فرعي مرتبط بقسم رئيسي.
- **إضافة درس صوتي**: اختيار ملف صوتي من الجهاز ← رفعه إلى `lessons/` في التخزين
  مع شريط تقدّم ← إنشاء وثيقة الدرس (العنوان/القسم/الفرعي/الرابط/مسار التخزين).
- **إضافة كتاب**: اختيار PDF ← رفعه إلى `books/` ← إنشاء وثيقة الكتاب.
- **التعديل والحذف / البحث**: بحث موحّد عبر الأقسام والدروس والكتب، مع إعادة تسمية وحذف.
  (حذف الدرس يحذف ملفه الصوتي من التخزين أيضاً.)
- **المشرفون**: عرض/إضافة/حذف المشرفين (لا يمكن حذف حسابك الحالي).
- **أدوات الصيانة**: تصحيح تواريخ الدروس (تعديل فعلي)، فحص التواريخ، فحص ربط الدروس
  بالأقسام (تقارير قراءة فقط).

## التشغيل
```powershell
flutter pub get
flutter run            # على هاتف موصول بـ USB (وضع المطوّر مفعّل)
```

## مخطّط Firestore (نفس مشروع التطبيق)
- `categories`: `{ name, createdAt }`
- `subcategories`: `{ name, categoryId, createdAt }`
- `lessons`: `{ title, categoryId, subcategoryId, audioUrl, audioStoragePath?, createdAt, views? }`
- `books`: `{ name, author, pdfUrl, createdAt }`
- `admins`: `{ username, password }`
- `devices`: للقراءة فقط (عدّ).
- التخزين: `lessons/<filename>` و `books/<filename>` في `gs://mxqp-8d1e8.firebasestorage.app`.

## ملاحظات أمنية مهمة
- تسجيل الدخول يطابق التصميم الأصلي: اسم/كلمة مرور **نصّيان** في Firestore دون تشفير،
  والكتابة تعتمد على قواعد Firestore المفتوحة للمشروع. هذا **ليس** نموذجاً آمناً؛
  يُفضَّل لاحقاً نقل الإدارة إلى Firebase Auth + قواعد تتحقق من دور المشرف.
- هذا التطبيق **إداري وليس للنشر العام على Google Play**؛ وزّعه يدوياً للمشرفين فقط.

## وظائف من اللوحة الأصلية لم تُنقل (مع السبب)
- **«تصحيح الروابط من Realm»**: كان يعتمد على قاعدة Realm محلية لم تَعُد موجودة.
- **«توحيد الصيغ (Opus)»**: نداء Cloud Function لم يكن موصولاً بزر فعّال في الأصل.
- **تسجيل معرّف الجهاز**: مسؤولية تطبيق المستخدم (أُزيل منه)؛ هنا يُعرض العدّ فقط.
